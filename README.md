# NightSpire-Survival

A 2D Roguelite Top-Down Survival game built with Godot 4.7.

## Overview
- **Engine:** Godot 4.7 (GL Compatibility, Pixel Art Nearest Filter)
- **Genre:** Roguelite / Action Survival / Tower Climber
- **Architecture:** Data-driven (`.tres` Resources), EventBus signal pattern, Strict GDScript typing
